# Restaurant App

Fitur:
- Halaman Daftar Restoran
- Halaman Detail Restoran
- Tema Gelap/Terang
- Loading Indicator
- State Management dengan Provider
- Error Handling
- Animasi Hero
- Pencarian
- Review

## Custom Icon App
1. Tambah icon di assets/icon
2. Command `dart run flutter_launcher_icons`

## Useful Command
```
flutter doctor
flutter clean
flutter pub get
fluter run
flluter run --verbose / --debug
dart fix --dry-run
dart fix --apply
```
